DeadKernel: a quieter Discord (early build, for a few friends)

Aditya's redesign of the Discord desktop app, built on Vesktop and Vencord. It changes how
Discord looks and is laid out. It doesn't read, send or store anything of yours anywhere.

WHAT'S DIFFERENT
- One sidebar instead of the server rail and channel list: who needs you (DMs and mentions,
  grouped per server), your favourites, recent DMs, then your servers.
- Opening a server opens its channels in a column beside the sidebar. Only the channels that are
  alive show (unread, recent, ones you've opened); "· N" after a category or "Show all quiet
  channels" unfolds the rest.
- Favourites are single things: a person, a group, a channel or a voice channel. Right-click >
  Add to Favorites, or the star in a conversation's header.
- Home (nothing open): friends in voice and who's live, requests, who's online, recent DMs.
- Ctrl K: jump anywhere. Empty, it lists where you just were and what's waiting. Type ">" for
  actions (mark mentions read, mute this server, stop @everyone pings in big servers, and so on).
- A calmer chat: one-line thread previews and replies, quiet reactions, a flat composer.

INSTALL (Windows or Mac, about 2 minutes)
1. Install Vesktop from https://vesktop.dev and log in as usual.
2. Unzip this folder somewhere it can stay (e.g. Documents\DeadKernel).
3. In Vesktop: Settings > Vesktop Settings > Developer Options > Vencord Location > Change,
   and pick the unzipped folder. Restart Vesktop.
To undo: same setting > Reset, restart. Your Discord account and the regular Discord app are
never touched.

IF SOMETHING LOOKS WRONG
Settings > Vencord > Plugins: "Sidebar" (the layout), "QuietLayout" (the chat), "Declutter"
(what's hidden), "HumanLayerTheme" (the look). Each can be switched off, and every option inside
switches live. If a part of the layout breaks, it falls back to Discord's own.
